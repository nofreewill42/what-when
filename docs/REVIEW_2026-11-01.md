## Checked and found correct

WSD warmup and cooldown; gradient accumulation (mean of equal-size micro-batch means); paired data order (a pure
function of seed and update); resume; validation windows (non-overlapping, every character scored once); BPC
(sum of NLL / n / ln 2); strided long-context evaluation (every character sees 769–1024 characters of context);
parameter and state accounting; gate thresholds and verdict logic against PLAN §5, including the fallback to R10
and to A2 long-context rows when there is no R40. Chunk 64 is numerically safe: fp32 chunked vs the fp64
sequential definition on adversarial key patterns (slow clocks, near-parallel keys) gives relative error ≤ 9e-7
for chunks 16, 32 and 64, and max |(I + A)⁻¹| = 1 because the Fejér Gram entries are non-negative.
